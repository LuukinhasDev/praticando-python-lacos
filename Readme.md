# Praticando Python: Laços for e while

Exercícios desenvolvidos durante o curso **"Praticando Python: Laços for e while"** (Alura), aplicando estruturas de repetição para resolver problemas práticos.

## Exercícios

- **Soma_de_Numeros** — soma os valores de uma lista usando for.
- **Compreendendo_lacos** — percorre uma lista de clientes com for.
- **Contagem_regressiva** — contagem regressiva com range() e condicionais.
- **Continue_em_lacos** — usa continue para pular itens de uma lista (estoque de livros).
- **Controle_de_Estoque** — simula baixa de estoque usando while.
- **Enendendo_uso_do_break** — usa break para interromper a busca em uma lista assim que encontra o item.
- **Loop_com_While** — exemplo de loop controlado com while e contador.
- **Mensagem_personalizada** — compara a repetição de uma mensagem usando while e for.
- **Organizando_lista** — percorre uma lista tratando valores ausentes (None) com continue.
- **Validacao_de_Entrada_login** — valida usuário e senha digitados, usando while para repetir a solicitação até os critérios serem atendidos.

## Como executar

```bash
python nome_do_arquivo.py
```
